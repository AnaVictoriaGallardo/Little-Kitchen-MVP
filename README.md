# Little-Kitchen-MVP
## Descripción
Este proyecto consiste en un programa desarrollado en Python para administra el inventario de una cocina y las recetas disponibles a partir de el. 
## Funcionalidades
- Catálogo base de ingredientes.
- Registrar nuevos ingredientes.
- Modificar cantidades.
- No permite ingresar ingredientes que ya se encuentran registrados
## Tecnologías y conceptos utilizados
- Python 3
- Listas y diccionarios
- Funciones
- Compresiones de listas
- Bucles
## Ejecución 
- Descargar el archivo cocina_personal.py
- Tener  Python 3 instalado
- Ejecutar el programa desde una terminal python cocina_personal.py
## Estado del proyecto
Es la base de este proyecto, a partir de esto se irán agregando más funcionalidades y complejidades.
